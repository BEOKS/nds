# gabia-request 사용자 교정 누적 규칙

이 문서는 `gabia-request` 스킬 사용 중 사용자 피드백으로 확정된 운영 규칙을 누적한다.

## 작성 원칙

- 사용자 교정이 나오면 같은 턴에 즉시 추가한다.
- 동일 주제 규칙이 충돌하면 최신 항목이 우선한다.
- 각 항목은 아래 형식을 따른다.

## 항목 형식

### YYYY-MM-DD
- 상황: (언제/어떤 요청에서 적용되는지)
- 규칙: (반드시 지켜야 하는 내용)
- 적용 방법: (이슈 본문/체크리스트/검증 로직에 반영 방식)

## 작성 예시

### 2026-03-04
- 상황: DB DDL 요청
- 규칙: DDL은 Confluence에 사전 작성하고 링크를 이슈 본문에 반드시 기재한다.
- 적용 방법: DB 템플릿 작성 시 `요청 Query` 또는 관련 섹션에 Confluence URL을 포함하고, 누락 시 생성 전 보완 요청한다.
