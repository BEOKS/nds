(DML의 경우 실행은 요청자가 DBSafer 승인을 통해 직접 실행하며 개발운영팀에서 문제발생 시 빠른 대응을 위해 작성합니다.)

|구분|내용|
|---|---|
|요청 부서|_요청 부서_<!-- 요청 부서 기록 -->|
|요청 기간|_적용 시점을 기준으로 작성_<!-- 적용이 필요한 시점을 기록, 생략 가능 -->|
|대상 DBMS|_오라클 / 가비아Total DB_<!-- 식별할 수 있는 DB서버의 정보를 기재 -->|
|요청 종류|_DDL / DML_<!-- DDL, DML 기준 준수 확인을 위해 입력 -->|


### 작업 설명*
* _어떤 작업을 위해 DDL/DML 실행을 요청하는지 구체적으로 작성_


### 사전 체크 사항*
* DDL
  - [ ] 쿼리 스키마 or ERD 문서 작성
  - [ ] 팀/유닛 내부 검토

* DML
  - [ ] DBSafer 쿼리 기안
  - [ ] DBSafer 2인 이상 결재


### 요청 Query*
* _다중 Query 의 경우 코드박스당 Query 하나씩 작성합니다._
* _Query 의 경우 Schema 포함하여 작성합니다._
```sql

```
```sql
--Query
```
```sql
--Query
```

_( 절차적으로 기록합니다. )_
```

--ex. 개발DB 기준 쿼리 실행 시간
--ex. 쿼리 실행 순서
```
